## Run
1. MySQL 8.0.16+ and Python 3.10+ are required.
2. `python -m pip install -r requirements.txt`
3. `mysql -u root -p < database/schema.sql`
4. `python scripts/generate_data.py --lenders 100 --seed 4211`
5. Load generated CSVs in the order listed in each dataset's LOAD_ORDER.txt.
6. Run `python scripts/validate.py --host localhost --user root`.
7. Run the benchmark separately after loading each population size.

**Evidence note:** Query outputs, actual MySQL errors and timings must be generated by running the scripts. This repository does not claim unexecuted results are measured observations.

**Design:** Independent LOAN occurrences contain LOAN_OBJECT custody lines. Condition reports reference the custody line. Legal ownership is separate, temporal ARTIFACT_OWNER history. DISPLAY_SLOT is weak and identified by (exhibition_id, slot_no).

Use enforced CHECK constraints in MySQL 8.0.16+. Cross-row rules such as ownership totals, interval overlap, slot scheduling and non-empty finalised loans require transaction-safe logic beyond a row-level CHECK.
